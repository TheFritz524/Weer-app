# Weer-app 🌤️

Een webapplicatie die historische weergegevens per locatie weergeeft.

## Functies

- 🔍 Zoek naar elke locatie wereldwijd
- 📅 Bekijk historische weergegevens voor een geselecteerde periode
- 🌡️ Zie temperatuur (max, min, gemiddeld)
- 🌧️ Bekijk neerslaggegevens
- 💨 Zie windsnelheid
- 📊 Automatische samenvatting van weerstatistieken
- 🎨 Moderne, responsive gebruikersinterface

## Gebruik

1. Open `index.html` in een webbrowser
2. Voer een locatienaam in (bijv. Amsterdam, Rotterdam, Utrecht)
3. Klik op "Zoek Locatie" om de locatie te vinden
4. Selecteer de start- en einddatum voor de historische gegevens
5. Klik op "Haal Weergegevens Op" om de weergeschiedenis te bekijken

## Technologie

- Pure HTML, CSS en JavaScript (geen frameworks nodig)
- Open-Meteo API voor weergegevens (gratis, geen API-sleutel vereist)
- Responsive design voor mobiele apparaten
